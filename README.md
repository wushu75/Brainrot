# Brainrot

**Your attention is being farmed. Here’s the score.**

Brainrot is a free, open-source Chrome extension that calculates your real **Brainrot Score** based on browsing behavior and helps you reverse it.

- Live Brainrot Score (0–100)
- 7-day trend + Attention Residual prediction
- Daily recovery plan
- Highly shareable report cards
- 100% local — your data never leaves your browser

Built for people who already joke about having brainrot.

## Install (Developer)
1. Clone the repo
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Load unpacked → select the project folder
